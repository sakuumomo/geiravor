# Contributing

How to work in this tree is [`AGENTS.md`](AGENTS.md). Product is [`docs/spec/`](docs/spec/). Repo contract is [`docs/`](docs/README.md).

Issues: **bug** (code disagrees with the spec) or **spec** (change the contract). Pull requests: one logical change, GPG-signed Conventional Commits. CI is [`.github/workflows/ci.yml`](.github/workflows/ci.yml).
