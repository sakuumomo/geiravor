# Security

Supported: the latest `1.x` release.

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/sakuumomo/geiravor/security/advisories/new) on this repository. Do not open a public issue for secrets, tokens, or exploitable bugs. Do not include NickServ, SASL, PEM, or CSRF values in reports.

This client talks to [r-a-d.io](https://r-a-d.io). Station-side issues belong there, not here.
