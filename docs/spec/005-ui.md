# 005 — UI

Compose, one Activity, not XML Views, not a WebView of the site.

## 0.1.0 screens

| Destination | Content |
|---|---|
| Now Playing | Play/stop, volume 0–100 (default 80), title/artist, collapsible tags, progress + mm:ss / mm:ss (AFK only; live DJ has no track clock), listeners, DJ image + `dj.djname`, thread link if present, previous track, next track |
| Songs | Last played and Queue as **separate cards**; Queue hidden entirely when not AFK; `/r/` + blue on `type == 1` |
| Settings | Auto-start on plug; auto-start in vehicle; about / version |

0.2.0 adds Request/Faves under Songs (or a dedicated tab) and News.

Always **tabs** (Now Playing \| Songs \| Settings), any width or aspect ratio. Do not two-pane.

## Layout

Follow the live homepage order for player chrome: play + volume, title, tags (+/-), progress + listeners + clock, DJ column.

Now Playing lists only the **previous** song (`lp[0]`) and **next** song (`queue[0]` when AFK). Live DJ (`isafkstream == false`): next is `???`. Full last-played and queue live on the Songs tab as two distinct blocks.

Tags: one space-separated line from `tags[]`, collapsed behind +/- like the site.

Times: relative from `timestamp` vs `current` (`002-api.md`).

Thread: phone only.

## Theme: live `default-dark`

Not the old app’s orange `#DF4C3A`. Tokens from `/assets/default-dark/css/bulma.min.css`:

| Token | Live | Use |
|---|---|---|
| `--radio-secondary-1` | hsl(0, 0%, 11%) | screen background |
| `--radio-primary-1` | hsl(0, 0%, 13%) | cards / bars |
| `--radio-primary-3` | hsl(0, 0%, 24%) | borders / raised |
| `--text-secondary` | hsl(0, 0%, 96%) | primary text |
| `--text-primary` | hsl(0, 0%, 50%) | muted text |
| `--blue` | hsl(208, 27%, 39%) | play / request / links |
| `--red` | hsl(348, 27%, 50%) | errors |
| `--green` | hsl(153, 27%, 39%) | success |
| `--text-link` | hsl(208, 27%, 50%) | links |

Play control uses the blue (`is-info` equivalent). Material 3 is re-skinned to these tokens.

Light and holiday/DJ CSS themes are later (`000-product.md`).
